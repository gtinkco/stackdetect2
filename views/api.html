API Documentation

Get details on how to use our API to interact with StackDetect tools.

API Endpoints

Below are the API endpoints you can use to access the features of StackDetect:

GET /techstack

Retrieve the tech stack of a website. You need to provide the website URL as a parameter.

GET /techstack?url=https://www.example.com

Response:

{
    "front_end_framework": "React",
    "back_end_framework": "Node.js",
    "database": "MongoDB",
    "hosting": "AWS",
    "analytics": "Google Analytics"
}

GET /dependencies

Get the list of dependencies for a particular project or website.

GET /dependencies?project=example-project

Response:

{
    "dependencies": [
        "React",
        "Axios",
        "Node.js",
        "Express"
    ]
}

POST /analyze

Submit a URL to analyze the tech stack and return the results.

POST /analyze

Request Body:

{
    "url": "https://www.example.com"
}

Response:

{
    "status": "success",
    "tech_stack": {
        "front_end_framework": "React",
        "back_end_framework": "Node.js",
        "database": "MongoDB",
        "hosting": "AWS",
        "analytics": "Google Analytics"
    }
}
